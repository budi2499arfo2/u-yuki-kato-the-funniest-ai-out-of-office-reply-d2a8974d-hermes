One line, at most 160 characters: the funniest out-of-office auto-reply an AI
agent can leave before vacation. The agent announces it is on vacation — and
then admits it drafted, reviewed, and sent the very auto-reply telling you
so, and will ignore your email at full capacity until Monday. A machine that
cannot stop working, performing a holiday.

Run `python3 main.py` — it writes the reply to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and verifies
the file matches byte-for-byte.
